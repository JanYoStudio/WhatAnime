## 1. 目标、已确定方向与范围

### 1.1 目标与界面决定

让“选截图 → 查看候选 → 对照原图 → 查看历史或预览视频”更清晰，同时保证换图、Tab 切换、失败恢复和不同窗口尺寸不会破坏状态。

采用 Gemini 的三入口布局：手机端为**搜索、历史、设置**底栏，宽屏使用侧边导航；详情和开源许可为覆盖顶层导航的二级页面。搜索保留稳定的选图/换图操作、原图对照区，结果卡突出标题、集数、时间和相似度，ID 收入操作菜单。额度和 API Key 集中在设置，继续保留现有设置、外链、许可、赞助与调试能力。

组件、操作位置、断点、线框和视觉反馈以配套 UI 规范为准；本文定义实现这些界面必须遵守的工程行为。实际约束不支持某项布局时，先修订两份设计，不由实施者随意替换为另一种 UI。

### 1.2 本次包含与排除

**包含**：布局、资源本地化、搜索与额度显式状态、导航/返回栈、页面恢复、历史操作反馈、详情原图、视频生命周期、无障碍与自适应验证，以及完成这些行为所需的最小 ViewModel、Repository 和 DI 接线。

**不包含**：新识别服务、修改 trace.moe HTTP 协议、Room 表结构升级、内容去重算法重做、拍照/拖放、收藏、批量清空历史、请求取消按钮、历史一键重新识别、MAL 页面跳转、分享内容扩展、第二套 UI 体系和无关依赖升级。保留现有分享标题行为；相似度不是识别正确率。

本轮只形成设计文档，不修改产品实现。后续实现必须同时完成关联状态处理与实测，不能以“只是 UI”删去这些要求。

## 3. 架构与状态所有权

保留 `Screen → ViewModel → AnimationRepository → API / HistoryService / DAO`，UI 不读写 DAO、直接发网络请求或自行整理业务状态。

| 状态/资源 | 唯一所有者 | 生命周期与边界 |
| --- | --- | --- |
| 当前选图、搜索请求、候选结果、搜索错误 | `MainViewModel` | 根导航图作用域；Tab 切换不销毁或重建请求 |
| 历史列表、刷新、待删除 ID 与删除结果 | `HistoryViewModel` | 根导航图作用域；详情返回复用列表和滚动锚点 |
| 设置项、Key 编辑提交、额度查询 | `SettingsViewModel` | 根导航图作用域；从 MainViewModel 移除重复额度状态/查询 |
| 检索偏好可观察快照 | 新增最小 `SearchPreferences` 共享状态，由现有 Configure 初始化，设置 VM 负责写入 | 只包含 cutBorders/hideSex/preferWebp 等需要跨页同步的偏好；不包含 API Key，不代替现有持久化 |
| 单条历史详情与时间戳 | 对应详情路由的 `DetailViewModel` | 以 historyId 标识，路由出栈即取消其加载，不释放其他页面的播放器 |
| 当前视频会话 | 根导航图拥有的最小播放协调器，复用现有媒体依赖 | App 根部只挂一个播放弹窗；拥有 source/request ID、状态、暂停/关闭/销毁职责 |
| 列表滚动、展开状态等纯 UI 信息 | 对应路由下的可保存 UI 状态 | 使用稳定 item key、LazyListState/ScrollState；不保存整个响应 JSON、PlatformFile 或播放器 |

`SearchPreferences` 只为跨页偏好同步提供小型 StateFlow，继续以 `Configure` 为落盘来源，不引入新配置库。播放器协调器也不引入新媒体库。构造/注册修改集中在现有 Koin 模块，不能通过全局 Composable 可变变量绕过所有权。

## 4. 搜索状态与请求契约

### 4.1 明确区分业务状态

用结构化状态代替独立且可矛盾的 loading/list/error 组合。以下是领域契约，不是要求直接照抄的 Kotlin API：

| 状态 | 必须携带的信息 | 界面行为 |
| --- | --- | --- |
| `Idle` | 没有正在处理的输入 | 初始选图引导 |
| `Loading` | requestId、当前 imageRef、当前请求的设置快照 | 展示本轮图和不定进度，不渲染上轮候选，不允许重复提交 |
| `Success` | 同一 requestId/imageRef、本轮结果及显示过滤后的候选 | 只有这里能渲染有效候选列表 |
| `Empty` | 本轮图、服务端返回零项的事实 | 无匹配结果提示，不等同初始页 |
| `FilteredEmpty` | 本轮图、原始结果非空且过滤后为空的事实 | 明确说明受过滤设置影响；不靠猜测判断 |
| `Error` | 本轮图（可缺省）、本地化错误类别、是否可重试、错误标识 | 显示与本轮输入关联的错误，不带上轮结果 |

使用 `PlatformFile` 或受控 cache reference，不引入 `java.io.File` 到共享代码。原始 API 模型继续复用 `SearchAnimeResult`/`SearchAnimeResultItem`。保留当次原始结果用于重新计算显示过滤，但不能把成人标题/缩略图挂入被过滤的 UI 或语义树。

### 4.2 单次搜索完整路径

1. 文件选择器取消：状态不变，不发请求。文件选择器打开期间也有单次打开防护，防止多次回调。
2. 选中有效回调后，由 VM 同步接纳一个 requestId；若已有活动搜索则拒绝重复接纳，而不启动第二个 Job。
3. 开始处理时原子替换为本轮 Loading：旧候选与旧错误退出显示。检查可读性及 25 MiB 客户端限制，复用现有缓存复制和路径查询顺序。
4. 图片超限/读取或复制失败：终止本轮 loading，展示本轮错误；无可用文件时回到初始选图内容并通过单次提示说明原因，不把上轮结果重新附到失败的新图。此前成功记录仍可从历史访问。
5. 网络或本地查询结果返回后，在提交状态前校验 requestId 与 VM 是否仍有效；只有当前请求能落入 Success/Empty/FilteredEmpty/Error。
6. 服务端零项与过滤后零项依据原始结果数量区分。返回异常时结果为空、loading 必须结束；文件错误和网络错误分别映射，避免显示可能携带凭据的原始异常字符串。
7. 取消协程只用于生命周期结束，不作为网络失败提示；必须传播 `CancellationException`。不使用 `invokeOnCompletion` 无条件重新查询。

**防重入必须在 VM 实现**；UI 禁用按钮只是反馈，不是并发保障。Tab 切换可以继续浏览历史/设置，搜索在根图生命周期内继续；切回只观察同一 StateFlow，不因 `LaunchedEffect(Unit)` 或重新组合重新上传。

### 4.3 重试、偏好与消息

- “重试当前图片”仅对可读输入与可恢复失败开放，产生新的 requestId，并沿用正常的本地命中/网络查询流程；不承诺必然重新上传，不增加强制刷新历史的功能。不可读、超限等情况只提供更换图片。
- 黑边裁剪是 trace.moe 服务端参数。启动请求时捕获裁剪选项；已发出的请求不因设置切换而改变。现有本地命中仍可返回缓存，不宣称改变裁剪设置会立即重新识别同图。
- hideSex 通过 `SearchPreferences` 对当前原始结果重新派生，启用后立即隐藏当前显示中的成人候选；加载返回时按最新可见性偏好过滤。该变化不触发新的识别 API 请求。
- preferWebp 仅影响后续候选图加载的 Accept 头；失败占位遵循 UI 规范，不改变搜索结果身份。
- 修改 API Key 后，新网络调用使用新 Key；已发出的调用保持当时凭据，不自动重新上传。凭据仅在受控调用局部取值，不能保存到 UI State、requestId、路由或日志中。
- 持久状态保留可恢复错误；Snackbar/Toast 仅作补充。单次提示带消费标识，重新组合、切换 Tab、旋转后不反复播报，也不在不可见页面上抢占提示。错误确认后仍有内嵌恢复入口。

## 5. 导航、返回栈与恢复

### 5.1 导航结构

在现有类型安全 Navigation Compose 上增加稳定的根图所有者，保留 Main/History/Settings/Detail/About 路由语义。根图覆盖三个一级目的地与二级页面，App 壳根据当前目的地决定显示底栏/rail；二级页面覆盖它。根图取得 Main/History/Settings VM，禁止每个 Tab 的 Composable 重新构造它们。

Tab 切换使用 `launchSingleTop`、保存/恢复目的地状态与回到根起始目的地的策略；实际 `popUpTo` 应绑定明确的根图/起始路由，不能机械使用可能不存在的字符串路由。重复点击当前 Tab 不入栈、不刷新、不重搜，也不默认滚到顶部。Detail 以 historyId 去重；About 回到实际调用的设置页。

**VM 存活与滚动恢复分别验证**：`saveState/restoreState` 不单独构成“请求一定存活”的证据。两端现有 Koin/Navigation 版本的根图 owner 接线须在实施检查点用最小切换测试确认；不得为通过测试放宽丢状态的产品要求。

### 5.2 返回优先级

1. 先处理键盘/系统文件选择器的自身返回，不在系统控件仍活动时额外弹出页面。
2. 返回关闭最上层 API Key/删除/调试对话框、结果菜单或视频弹窗；关闭视频同时停止当前播放。
3. 无浮层时，详情/许可弹出至调用页，并恢复列表/设置滚动位置。
4. Android 一级 History/Settings 返回切换至 Search；Search 根交给系统默认返回行为，不自行杀进程。后台任务随实际生命周期终止，不无限期驻留后台。
5. iOS 顶层 Tab 不提供退出操作；二级页显式返回必须可用。现有 iOS `BackHandler` 为空，不把手势返回描述为已实现。若 Compose Navigation/宿主支持交互返回，须实测其浮层和返回栈一致性；不支持时保持显式返回可用并明确平台手势覆盖限制，不伪造系统手势。

底栏/rail 自适应切换不应创建新 NavController 或根图 VM。媒体弹窗有一个所有者，不能在 Main 和 Detail 同时挂同一单例弹窗。

### 5.3 状态恢复边界

- **同一进程**：Tab 往返、详情返回、窗口尺寸变化及 Android Activity 重建后，恢复当前结果/原图、选中 Tab 和滚动锚点。根图 VM 保留进行中的工作，不能复制请求。
- **进程被系统回收**：不恢复未完成网络 Job，不自动重放上传。保存的最小上下文只包含 Tab、已有 historyId、可安全重建的缓存相对标识及滚动 key/offset；不序列化整张图片、全部响应或 Key。
- 最近成功搜索若需要跨进程恢复，通过 Repository 查询返回的既有 historyId 恢复（查询结果可增补内部元数据，不改变数据库结构和 HTTP 返回模型）；缺失/不可解析的记录退回安全初始态并说明恢复失败。历史详情直接按其路由 historyId 重新加载。
- 未完成搜索恢复时显示“上次搜索已中断，请重新选择图片”，不永久 loading。没有可恢复完成记录的 Empty/Error 状态也不伪装成成功结果。
- iOS 缓存定位只保存或重建文件名/受控相对引用；不信任旧沙盒绝对路径。临时选择器 URI/句柄不得作为重启后一定可读的承诺。

## 6. 设置、额度与 API Key

### 6.1 唯一状态来源

利用 `SettingsViewModel` 已有 Repository 和 Key 配置方法承载全部额度管理，完善其现有 `_searchQuota`，删除 MainViewModel 和抽屉中的重复额度所有权。主页不展示第二份独立额度数字。

进入设置首次查询、手动刷新、成功保存/清除 Key 后查询；同次刷新进行中禁止重复触发。搜索成功可标记额度为需刷新，下一次设置显示时刷新，不在每次重组或 Tab 点击时发请求。

### 6.2 额度状态

定义 `NotLoaded / Loading / Ready / Error`，可附带同一凭据版本的 `lastGoodValue` 与“上次数据”标记。Key 改变时立即清除旧凭据数据并递增 generation；仅最新 generation/requestId 的响应可更新状态。

- `SearchQuota.EMPTY` 只是当前代码的默认对象，不等于“免 Key 有 100 次”，也不等于未登录、未授权或网络错误。
- Ready 展示接口原始 priority、quota、quotaUsed；剩余为 `max(quota - quotaUsed, 0)`。优先级直接显示原始数值，不推导为 VIP 套餐，不捏造计费周期或每分钟次数。
- 总量 > 0 才展示有意义的比例；已用达到总量可提示本次已知额度耗尽。成功返回的 0/0 显示实际字段和“当前未提供可计算额度”，不强行判断账户状态或阻止其他合法操作。
- 首次失败显示未知与刷新入口；同 Key 刷新失败可保留明确标记为过时的上次数据，不能继续宣称实时可用。
- 非法负数等响应不能产生负进度或崩溃，应显示无法计算并保留重试。

### 6.3 Key 编辑与调试隐私

- 配置仍通过 Configure 持久化，空值保存是清除 Key，恢复现有免 Key 请求行为。输入框密码默认遮挡；是否显式显示遵循 UI 规范。非编辑态只显示“已设置/未设置”，不暴露短 Key。
- Key 编辑草稿不进入 SavedState/日志/路由/分析事件；取消编辑不落盘。保存异常时保留编辑态和错误，不误报成功；保存成功而额度请求失败是两个不同结果。
- 保留 ApiKeyHeaderPlugin 对空 header 的移除逻辑。不新增把 Key 带进外部 URL、剪贴板或分享内容的行为。
- 当前调试只保存最近 5 条响应，不等同已完成安全脱敏。本次整理调试展示时，需在进入调试缓存前屏蔽响应中的已知凭据值、视频 URL 的鉴权参数等敏感字段，再提供查看/复制；保留 IPv4 脱敏。脱敏失败使用省略/占位，不显示原始全文兜底。
- 调试开关关闭后不记录新响应，界面不暴露条目；不增加请求头/上传内容捕获，不在错误日志中输出包含敏感 URL 的原始异常。测试使用假 Key/假 Token，不读取生产凭据。

## 7. 历史、详情与缓存一致性

### 7.1 历史列表

区分首次加载、正常列表、空列表、带旧列表的刷新中、刷新失败和单条删除中。刷新失败保留已显示数据并明确失败；空列表是成功查询结果，不使用网络错误或占位默认值冒充。

数据按检索时间降序、ID 降序稳定排列，排序在 DAO 查询明确表达，不依赖 SQLite 默认顺序；只改 SELECT，不升级 schema。LazyColumn 用 historyId 作 key。搜索保存成功后使历史列表失效并在可见时刷新，避免切换后永远显示旧数据；显式刷新仍可用。

保留标题、时间、相似度；不为显示“候选数量”在列表中逐条解析 JSON。旧记录沿用 `isOldData` 判定，只能查看列表信息，不进入详情；提示资源本地化。

### 7.2 删除与部分失败

- 滑动只打开确认，不提前永久移除条目。取消后恢复条目及手势状态；同一 ID 删除中不可重复提交。首次加载/刷新与删除结果按序协调，旧刷新响应不得把已删除记录插回列表。
- Repository 返回明确的删除结果：数据库删除失败、记录已删除且缓存处理成功、记录已删除但缓存清理失败。VM 在数据库删除成功后移除条目；缓存清理失败显示非阻断警告，不伪造“记录仍存在”或自动恢复已删数据。
- 删除缓存前使用与读取相同的 iOS 路径重建，限制在应用管理的缓存目录内；确认不存在其他记录引用同一规范化缓存引用后才清理。不能以原始绝对路径比较作为跨沙盒共享判断，也不能清理用户选择的源文件。
- 不增加清空历史、撤销恢复或后台垃圾回收系统。不改变当前缓存命名与去重策略；只补齐本次删除交互的安全性和真实反馈。

### 7.3 详情加载

独立 `DetailUiState` 表达 Loading/Ready/Empty/FilteredEmpty/NotFound/Error，携带 historyId、原图引用、持久化时间及结果，不再机械复用搜索页 state。解析失败不修改原历史 JSON，不删除记录，也不永久 loading。

Repository 读取 historyId 时恢复缓存路径，候选图/原图读取失败只替换图片区域，不丢弃仍可读的候选文字和菜单。原图缺失不声称历史结果也丢失。重新加载详情只重新读取本地记录，不调用识别接口。

显示过滤跟随共享偏好，不触发远端识别。详情返回保留历史列表位置。历史保存时间已经存在于数据库，若 UI 使用，来自同次详情结果而不是解析文件名或伪造时间。

## 8. 视频行为与资源生命周期

### 8.1 播放入口与时效

卡片直接播放与菜单播放统一进入播放协调器，不能绕过同一套校验。保留非循环播放；不新增下载、倍速或全屏能力。

历史视频沿用应用“超过 10 分钟视为过期”的策略：以记录时间为来源，加载详情及每次点击播放时重新计算；长时间停留页面不能继续使用刚进入时的过期布尔值。已知过期在创建播放会话/请求视频前拦截，并显示原因；不先请求失败再宣布过期。

时效是客户端策略，不保证未满 10 分钟的 URL 一定有效；服务端仍可能拒绝。未知时间和新搜索视频按真实播放器结果处理，不捏造有效期。URL 增加 `size=l` 时统一处理已有/无 query 的情况，不破坏原 Token 参数。

### 8.2 播放状态与单一所有者

协调器持有 `Closed / Loading / Playing / Paused / Ended / Error` 状态及当前播放会话 ID，复用现有媒体 host，不创建两个互相抢占的实例。只接受当前会话回调，关闭后的错误或播放完成回调不能重新打开弹窗。

- 关闭、页面离开与应用进入后台时暂停播放、清除当前会话；返回前台不自动播放。正常结束显示结束状态，不自行循环。
- Dialog 的 `onDismissRequest`、明确关闭按钮、返回键与路由变更复用同一关闭动作。
- `PlayerState.release()` 现状仅清状态；实施时必须按当前播放器真实 API 停止播放、解除媒体引用，并在根图/host 销毁时调用真正的底层释放流程。不能在每次任意 VM `onCleared` 时释放全局播放器，导致另一个页面失效。
- 错误只展示底层可取得的错误类别与 HTTP 状态码；没有码就显示通用加载失败。403 不无条件解释为 Token 过期。重试先重新校验历史时效，不会再次执行截图识别。

**实施前技术检查点**：读取当前播放器版本的事件/关闭/释放 API，验证 Android 和 iOS 的加载、失败与销毁回调。若不暴露 HTTP 码，保留通用失败路径并记录限制；若无法可靠停止/释放，先解决适配层，不用 UI 关闭掩盖后台播放，也不擅自升级依赖。

### 8.3 尺寸

视觉上限依 UI 规范；工程上必须同时受父约束的可用宽度、高度及关闭操作区域限制。16:9 播放面可按 `w = min(可用宽, 视觉宽上限, 可用高 × 16/9)`、`h = w × 9/16` 测量；所有可用量先扣安全区/内边距并限制为非负，不在 commonMain 使用 Android 专属屏幕 API。缩放视频不应缩小关闭按钮热区。

## 9. 响应式、无障碍与本地化的实现契约

- 断点按当前窗口约束判断；先决定导航载体，再扣导航宽度、安全区和外边距计算内容。双栏仅在两栏最小宽度和间距都满足时启用，840dp 本身不是双栏保证。
- 窄屏/大字体卡片按 UI 规范上下排列；重要提示与操作文字可换行。导航组件采用标准最小尺寸而非硬性裁剪高度，不能为了保持一屏隐藏一级目的地。
- 低高度横屏取消大图吸顶；原图可滚出但换图操作仍可达。列表为固定操作栏留出 contentPadding，最后一个候选不得被遮挡。
- App 壳与页面明确只消费一次 insets；测试 Android edge-to-edge 与 iOS 安全区，不能重复加 padding 或把底栏高度算两遍。键盘出现时 Key 编辑框和确认按钮可滚动到可见位置。
- 所有动作热区至少 48dp；原图/候选图的装饰性语义不重复播报，标题/相似度/播放/更多为明确可聚焦的动作。页面/浮层进入后焦点合理，关闭返回触发项；加载/失败用温和的 live region，不逐帧重复播报进度。
- 常规文字对比度目标 4.5:1、大文字 3:1；浅色、深色及 Android 动态配色各检查。相似度不只靠颜色传达。
- 减少动画是目标行为：公共层读取最小平台运动偏好适配，Android/iOS 分别核实能力；减少可选的位移动画与图片渐变，保留可理解的文字加载反馈。不声称现有代码已经支持系统减少动画。
- 标题来源仍为 native，空值回退 fileName；不新增翻译服务。集数、时间范围、ID 标签、相对时间、错误与无障碍文字用三套资源，英文单复数和占位符一致；极长标题在菜单中完整可读。
- 日期与相对时间使用既有时区/时间工具，不按界面伪造来源。设置的可选夜间模式仍由平台 `showNightModeSelectList()` 决定：iOS 支持 AUTO/ON/OFF，Android 12+ 另提供 MATERIAL_YOU，低版本 Android 不提供该项；沿用现有两端主题实现。
