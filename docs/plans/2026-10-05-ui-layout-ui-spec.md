# 界面布局与交互规范

- 成文日期：2026-10-05
- 状态：**整体书面方案已由用户确认（2026-10-05），已授权实施；尚未完成实现或实测**。
- 本规范由 Gemini 主导界面设计，经源码与契约复核后整理。状态、导航所有权、数据兼容及验证责任见[整体设计](2026-10-05-ui-layout-design.md)；本文维护视觉与用户交互，不维护第二套工程状态机。

## 1. 目标与边界

WhatAnime 的核心动线是“选择动画截图 → 浏览候选 → 对照原图 → 预览片段或访问历史”。本次采用三入口导航、常驻主操作、紧凑原图对照与精简结果卡片，继续使用 Compose Multiplatform + Material 3 和既有主题，不新增 UI 依赖。

- 图片上限 **25 MiB** 是当前客户端大小检查，不推断服务器限制或保证所有图片格式均受支持。
- similarity 仅显示接口相似度数值，不表示正确识别概率，不作红绿可信度分级。
- 标题来自 `native ?: fileName`，不保证中文译名。
- 不新增拍照、拖放、收藏、批量清空、重置工作区、取消请求、历史一键重新识别、MAL 外链或分享内容扩展。
- 界面所有示例名称、文件名、时间、版本和额度均为线框示意，不是当前应用数据。

## 2. 全局导航与操作锚点

### 2.1 三个一级目的地

- **搜索**：选图、搜索状态、原图及候选结果。
- **历史**：本地记录、详情入口、单项删除。
- **设置**：额度、Key、检索偏好、外观、调试和关于。

History/Settings 是一级 Tab，不放无意义的顶栏返回箭头。Detail/About 是二级页面，完整覆盖底栏或侧栏，有明确的顶栏返回按钮。

导航选择按扣除系统安全区、尚未扣除导航控件的窗口可用约束计算，优先判断高度：

| 条件 | 导航载体 | 标签与尺寸 |
| --- | --- | --- |
| 高度 >= 480dp，宽度 < 600dp | 底部 `NavigationBar` | 三个图标和文字；使用 M3 默认最小高度，随字体和安全区增长，不硬裁剪 |
| 高度 >= 480dp，宽度 >= 600dp | 左侧 `NavigationRail` | 目标宽80dp，保留目的地标签；大字时可增宽，内容宽重新计算 |
| 高度 < 480dp，宽度 >= 480dp | 常驻左侧紧凑 rail | 目标宽72dp，仅图标，无可见标签 |
| 高度 < 480dp，宽度 < 480dp | 常驻左侧极简 rail | 目标宽56dp，仅图标；主内容按实际剩余宽度使用上下卡片 |

紧凑 rail 不渲染文字标签，包括选中项；不能仅设置一个仍会显示选中标签的参数就认为满足规范。图标24dp，每项触达至少48×48dp，读屏提供完整目的地名称和选中状态。低高度仍能切换全部三个 Tab；极端高度不足容纳三项时导航区域可滚动，不以删除入口换取空间。56dp rail 不保证内容必然剩余300dp，需按实际约束继续回退。

### 2.2 主操作统一为常驻右下角 FAB

搜索页在所有状态中保留同一个操作锚点，不在顶栏、原图卡和底部之间来回迁移：

| 搜索状态 | FAB 文案与行为 |
| --- | --- |
| Idle | Extended FAB：“开始搜索”，调用系统图片选择器 |
| Loading | 位置不变，视觉与无障碍状态均为不可操作；不重复提交 |
| Success / Empty / FilteredEmpty / 可恢复 Error | Extended FAB：“更换图片”，重新选图 |
| 文件超限/无法读取而回到 Idle | “开始搜索”；通过单次提示解释上一输入失败 |

单栏时距内容右侧、底部安全边缘各16dp，并位于底栏之上；列表向下滚动时可收缩成56dp图标 FAB，静止时展开。收缩不改变右下角锚点与动作语义，减少动画模式下直接切换形态。短高横屏仍为内容右下角；大屏双栏锚定**左侧输入工作区右下角**。

原图卡片内不再放换图 Chip，顶栏不再重复放换图/重置。重试当前图是错误卡内的次级动作，不占用或替换主 FAB。列表底部为 FAB 留出足够空间，最后一个候选和菜单入口不得被覆盖。实现禁用交互应使用组件真实能力及语义/VM 防护，不假定 FAB 一定提供 `enabled` 参数。

### 2.3 返回与状态保持

浮层优先关闭，其次二级路由返回，再执行一级 Tab 返回规则。Android 在 History/Settings 返回 Search，Search 根交给系统；iOS 不主动退出进程，二级页显式返回必须可用。iOS 手势支持需实测，不作为当前已有事实。

切换 Tab、尺寸变化和二级页返回应保留原图、候选及滚动位置；加载期间切换 Tab 不取消或重复提交当前搜索。具体 owner、恢复边界、进程回收和迟到响应规则统一见整体设计第3–5节。

## 3. 搜索页

### 3.1 初始态

TopAppBar 展示应用名称，不放重置按钮。主视区展示简洁矢量图、选图提示和“文件大小上限25 MiB”说明；不用工作室图片充当搜索输入。装饰图不参与读屏，主要引导使用正文。

右下角保留“开始搜索”Extended FAB。窄屏、大字、短高下引导内容可滚动，不强求所有内容在一屏内。

### 3.2 原图对照卡

使用 `ElevatedCard`，水平外边距16dp，垂直8dp；内部左侧为112×63dp、圆角8dp的缩略图，右侧为“当前检索图片”辅助标签和文件名（最多两行，超出省略）。原图缩略预览使用裁切展示，不修改实际上传/缓存文件；不添加当前没有的数据如像素尺寸。

卡片高度自然测量，不固定为140dp。字体 >= 1.5 时允许自然增长；卡片可用宽度不足360dp时回退为上图下文，缩略图保持比例。正常单栏结果态吸顶保留紧凑对照；可用高度 < 480dp 时取消吸顶，成为普通列表首项。主 FAB 不属于滚动内容，因此原图滚出后仍可换图。

双栏时原图位于左工作区。原图加载失败仅在图片位置显示明确占位及“无法显示原图”，不让有效的候选文字随之消失。

### 3.3 搜索状态反馈

| 状态 | 主体反馈 | 次级操作 |
| --- | --- | --- |
| Loading | 原图卡底边不定线性进度，结果区3个低对比度灰色微光骨架卡及“正在搜索中” | 无取消、无重复提交；可切Tab |
| Success | 原图+本轮候选列表 | 卡片播放/菜单 |
| Empty | 原图+无结果占位，建议更清晰的截图 | 常驻换图FAB |
| FilteredEmpty | 说明“结果已被成人内容过滤设置隐藏”，不显示被过滤标题/缩略图 | 跳转设置检查过滤项 |
| 网络/服务失败 | 原图+本地化内嵌错误，Snackbar仅补充 | 可恢复时“重试当前图片”；语义为正常查询，不保证强制上传 |
| 超限/读文件或复制失败 | 安全回到初始选图内容并提示原因，不携带旧图的候选 | 重新选图 |

Loading 不展示上一轮候选，不伪造“特征提取”等没有真实进度的阶段。减少动画模式下微光变成静态占位，文字反馈保留。Empty/FilteredEmpty 由显式状态决定，不单凭 `list.isEmpty()` 判断。

### 3.4 候选结果卡片

- 使用 `ElevatedCard`；外边距16dp、间距8dp，沿用 Material typography 与 colorScheme。
- 常规宽度左图右文，候选缩略图16:9，目标宽128–140dp；Coil 负责加载，占位为低对比度块，失败使用既有失败图标。
- 标题采用 `native ?: fileName`、titleMedium，最多三行；集数与时间区间采用现有格式化逻辑；缺失字段不显示“null”或虚构集数。
- 相似度单色、保留既有小数格式；语义读作“相似度百分之……”。ID 不占卡片正文。
- 卡片可用宽度 < 360dp，或字体 >= 1.5 且宽度 < 400dp 时改为上图下文；以卡片实际约束判断，不只看整块屏幕。

**点击区域分开**：缩略图中央有播放标识，整个缩略图区只触发预览；文字区、更多按钮及其余主体区域打开操作菜单。二者不可重叠或冒泡触发两次，分别提供播放与查看操作的读屏语义。上下排布后也保留这两个区域。播放入口与菜单预览使用同一校验，不绕过过期检查。

### 3.5 结果操作菜单

菜单头展示完整原生标题，多行自然折行；**不以四行省略号或跑马灯代替完整标题**。整个菜单可垂直滚动，确保极长标题和大字体下六类操作都可达。关闭菜单后焦点返回触发区域。

保留六类已有能力：复制标题、复制 AniList ID、复制 MAL ID、分享标题、打开 AniList、预览视频。按数据是否具有有效ID显示/启用对应动作，不能生成 `/anime/null`。ID复制只复制数字；分享仍然只分享标题；不新增 MAL 外链、时间/链接分享。菜单播放与缩略图播放一致。

## 4. 历史与详情

### 4.1 历史列表

一级页面顶栏显示“历史记录”，保留下拉刷新，不放批量清空。首次加载使用居中环形进度；后续刷新保留列表和下拉指示器；失败保留旧数据并提供提示/重试，成功空列表才展示“暂无历史”。

条目统一 `ElevatedCard` 图文结构，展示 `history.cachePath` 缓存缩略图、title、检索时间、非旧记录的相似度。时间文案三语本地化，不显示需要额外逐条解析JSON才获得的候选数量。窄屏/大字沿用候选卡回退规则。

左滑露出删除背景与图标，达到阈值先弹确认；取消后条目复位。确认期间该ID不可再次删除。数据库失败仍显示条目；记录已删除但缓存清理失败时，条目移除并明确提示清理问题，不能把部分成功写成全部失败。安全清理细节见整体设计。

旧记录沿用 `isOldData`：`episode == "old" || similarity == 0.0`，没有 `data_version` 字段。点击旧记录提示无法查看详情，不进入详情，不强制用户删除。

### 4.2 历史详情

二级页面覆盖导航，有显式返回和“历史详情”标题，不新增页级分享。加载时展示进度，完成后显示当时的原图与候选，原图走规范化的缓存路径。原图丢失显示可换行说明，不用固定80dp裁掉大字，不影响仍可读的候选。

状态必须区分：加载、正常候选、零结果、过滤后空、记录不存在、读取/反序列化失败。不存在提示返回历史；读取失败提供重新加载本地数据；不能全部显示“无结果”，也不能偷偷重新调用识别API。

视频超过记录时间10分钟时，在卡片/菜单前置提示已过期；用户点击时再次检查，**请求视频和打开播放器之前**拦截。未过期不代表服务端一定可播，真实失败仍走视频错误反馈。保留过期解释，不新增历史一键重搜。

## 5. 设置与开源许可

### 5.1 设置页信息结构

设置为一级可滚动页面，顶部为额度卡，其下按以下顺序分组，保留全部现有能力：

| 分组 | 内容 |
| --- | --- |
| 额度 | priority、quota、quotaUsed、可计算的剩余与进度、刷新 |
| 检索 | 服务端黑边裁剪、隐藏成人内容、优先WEBP |
| 外观 | 平台实际提供的夜间模式选择 |
| 服务与凭据 | trace.moe API Key 编辑 |
| 故障排查 | 调试开关、最近5条响应及查看/复制 |
| 关于应用 | 项目GitHub、项目许可证、工作室许可、商店链接、版本、设备ID复制、开源组件列表 |
| 关于trace.moe | 开发者soruly、trace.moe主页、GitHub Sponsors与Patreon赞助入口 |

黑边说明是服务器匹配前裁剪，不是本地上传前处理。preferWebp 保留现有候选图加载偏好。Android 12+ 支持 AUTO/ON/OFF/MATERIAL_YOU，低版本和iOS为 AUTO/ON/OFF，直接由现有平台选项函数给出。

外链复用现有资源与 `UriHandler`，不发明新增商店Intent或Key获取链接。版本取现有 `appVersionName()`；设备标识不可宣传为已经审计的匿名ID。赞助对象明确是 trace.moe 作者soruly，而非应用开发者，保留两个现有赞助渠道。

### 5.2 额度卡

`ElevatedCard` 外边距/内边距各16dp，完整数字可自然换行。只展示接口实际字段，不展示未定义的VIP等级、免费默认100次或每分钟/每月周期。

| 数据状态 | 展示 |
| --- | --- |
| NotLoaded | 未获取信息，数字占位；刷新可用 |
| Loading | 正在获取，刷新禁用；若有同Key旧数据必须标记为上次值 |
| Ready且总量>0 | priority原始数值、总量/已用/剩余；剩余不小于0；可显示已用比例 |
| Ready且0/0 | 显示真实0值和“当前未提供可计算额度”，不伪造比例/账户状态 |
| Ready且已用达到有效总量 | 明确本次已知额度耗尽，不和查询失败混淆 |
| Error | 查询失败+刷新；旧数据仅以过时标识保留，不当实时额度 |

请求失败和未获取不能仅根据 `SearchQuota.EMPTY` 猜测。Key变更后不得短暂展示前一个Key的额度。

### 5.3 Key编辑与调试

- 非编辑态一律只显示“已设置/未设置”，不露末尾字符，包括短Key。
- 编辑对话框默认密码遮挡，允许用户显式切换可见；提供取消和“保存并刷新”，无自动复制。
- 空值保存清除Key；保存失败留在编辑态，配额查询失败不误报Key保存失败。输入及确认按钮随键盘和滚动保持可达。
- 调试仍为最多5条响应，不新增请求捕获。当前实现只有IPv4替换，不能说已经完整脱敏；目标展示/复制须消费按整体设计处理过的安全内容。调试对话框长文本可滚动，复制与关闭按钮始终可达。

### 5.4 开源许可页

二级页有返回，复用 AboutLibraries 组件和原 AppInfo 头部。加载时有反馈；加载失败显示错误与本地重试，不崩溃、不跳到识别请求。保留许可证展示与既有组件能力，不另建依赖管理界面。

## 6. 视频弹窗

保留非循环预览，无新增全屏、下载等动作。全App只有一个播放弹窗，具体所有权见整体设计。

- 视口同时受父容器可用宽、高约束，维持16:9；常规目标宽不超过 `min(可用宽×0.9, 480dp)`，目标高不超过 `min(可用高×0.7, 320dp)`；短高视口允许高占比至0.85，再结合宽约束缩小。
- 独立关闭按钮至少48dp热区；关闭、系统返回、点外部均进入同一关闭流程，背景不得继续响声。
- Loading 显示环形进度与加载文字；Playing/Paused/Ended 使用现有播放控件及结束反馈，不自动循环。
- 底层确实提供HTTP码时展示对应本地化错误；403不直接当过期，未知码显示通用失败，不虚构状态。可重试时重试当前视频，但先重新检查历史时效。
- `PlayerState.release()` 当前只是清标志，目标需要实际停音、清理媒体引用及生命周期释放，不能只关闭UI就宣称资源已释放。

## 7. 响应式、无障碍与本地化

### 7.1 单栏与双栏

导航载体先按第2节确定，然后从窗口约束中扣除实际rail宽、安全区和外边距，得到内容宽；不能在已扣除的约束上再减一次。

双栏要求左栏至少380dp、间距24dp、右栏至少380dp，即内容宽至少784dp。常规80dp rail、两侧合计32dp边距时，对应未扣rail的窗口可用宽至少896dp，**840dp不是双栏保证**。低高度统一使用单栏滚动，不因宽够就恢复大图吸顶。

双栏左侧为原图/状态与主FAB，右侧为独立候选列表；低高度或剩余宽不足时回退单栏，保持同一数据与滚动上下文。

### 7.2 安全区与动态字体

- 验证320/360/600/840dp及满足双栏的大窗口，以及高度<480dp的横屏。
- 字体1.0/1.5/2.0；标题在卡片可省略，菜单完整阅读；错误、操作与导航不可因定高裁切。
- API Key键盘避让、Android系统栏、iOS安全区、底栏/rail切换不遮挡内容。
- FAB下方与列表末尾留空由实际组件尺寸决定，不用固定小padding导致最后一项被覆盖。

### 7.3 无障碍与运动偏好

独立动作热区至少48×48dp，播放和菜单有不同焦点。图片若仅重复文字语义可不朗读；按钮必须有用途描述。浮层进入合理聚焦，关闭回到触发动作；加载/错误文字不高频重复播报。

正文对比度目标4.5:1，大字3:1，深浅色及动态色分别实测。减少动画模式下取消可选位移、微光与图片渐变，保留静态加载文字；跨平台能力需工程适配，不视为现状已支持。

### 7.4 本地化

所有新文案及既有中文硬编码按范围抽取到英文、简体、繁体三套资源。集数、相对时间、错误、按钮与无障碍语义保持占位符一致。规范中的新文案是设计文本，不宣称已存在对应资源键。

## 8. 低保真线框

以下示意仅表达结构；文字、时间、版本与数值不是当前真实数据。标题不补造中文译名。

### 8.1 初始页

```text
┌─────────────────────────────────┐
│ WhatAnime                       │
├─────────────────────────────────┤
│          [简洁矢量图]           │
│       选择动画截图开始搜索       │
│         最大 25 MiB             │
│                                 │
│                   [开始搜索 ＋] │
```
